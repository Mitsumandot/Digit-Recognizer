# Digit-Recognizer
The purpose of this project is to create a Neural Network that recognizes handwritten digits from scratch using only Numpy.
It’s a practice project that might seem a bit useless, since you can achieve the same thing in just a few lines of code using libraries like TensorFlow or PyTorch. However, I’m doing it because I’m fascinated by the mathematical concepts behind Neural Networks, and I want to understand how they come up with their weights and biases, and how the backpropagation algorithm truly works.
